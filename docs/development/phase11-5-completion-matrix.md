and affected reclamation. B's existing functional HTTP evidence is retained;
keep its tested image until a concrete assigned case requires alignment. B may

scheduling. A held/uncertain record survives process exit; a lock timeout never

schedule-disabled evidence. The unchanged conducted setup is user-confirmed.

counts/bytes/rates/identities/deadlines and cleanup before execution.
