## Code review and implementation implications

| Source | Finding |
| --- | --- |
| [Control HTML](../../src/network/web/index.html) | Header identifies the product; H1 is `Your station`. Shared login/status appears above both task areas. The prominent `Pico <full ID>` is generated by JavaScript, not a literal heading to replace. The current hostname summary is separate from that login identity. |
| [Control script](../../src/network/web/app.js), `discoverLocal` and login handler | Consumer discovery sets `local-status` to `Pico ${localIdentity.device_id}`; login changes it to `Authenticated for Pico ${localIdentity.device_id}`. Engineering SoftAP discovery prints `Device <ID> · <surface>`. Error handling also writes the same status element. A one-time substitution would be overwritten by later states. |
| `app.js::presentationTitle` | Consumer pre-login title already reads `/api/consumer/v1/presentation`, validates `device-presentation/1`, matching full device/boot IDs and canonical hostname. It currently updates only `document.title`. Its data is nonsecret presentation, not proof of authentication or RF authority. |
| `app.js::refresh`, `readHostname`, `markTitleStale`, hostname submit | Multiple writers update tab titles. Authenticated `transmitter-hostname/1` supplies saved/active/default name, target and pending restart. Titles use **active** name, retain rename-pending state, and mark failures last-confirmed/unknown. Identity on the page must follow the same semantics. |
| [Consumer adapter](../../src/network/consumer_radio.cpp), [client](../../src/network/bootstrap_web/radio-client.js) | Public presentation and exact-key-set identity/1 are distinct routes. Consumer sessions remain full-device/boot/profile bound. No schema extension is needed merely to render the existing hostname. |
| [Browser API](../../src/network/api.cpp), [SoftAP adapter](../../src/network/softap_api.cpp) | Engineering local identity contains device ID but no boot ID or hostname; application/hostname resources provide authenticated member targets. `capabilities.wtp` contains capabilities, **not device ID**. Do not build Diagnostics around a nonexistent capabilities ID or change legacy identity keys to obtain it. |
| [Hostname settings](../../src/provisioning/hostname.cpp), [network status](../../src/standalone/pico/adapters.cpp), [identity rules](../../src/network/identity.hpp) | Persisted/saved, boot-active, default/stable and advertised hostnames are different observations. Firmware keeps active boot identity until restart. Canonical `.local` grammar is one 1–63 ASCII LDH label plus `.local`; the full canonical name can be 69 characters. MAC-derived default is not the full stable device ID. |
| [Area navigation](../../src/network/web/organization.js) | `/station` and `/wifi-host` share one document and session. History/back/forward and section/receipt hashes select presentation only. Put primary identity and About/Diagnostics in shared chrome, reachable from either area, without reauthentication or navigation side effects. |
| [Setup presentation](../../src/network/bootstrap_web/presentation.js), [tests](../../src/network/bootstrap_web/presentation.test.mjs) | AP commissioning pages already obtain hostname-first titles from their existing nonsecret endpoint. They remain separate workflows. Their helper takes an expected device ID and validates a boot-ID shape; its contract differs from the consumer control helper's exact boot match. Do not conflate the two or require a boot field absent from a carrier's identity. |
| [Asset generator](../../scripts/generate_web_assets.py), [CMake inputs](../../CMakeLists.txt) | Control scripts/CSS are embedded and streamed with CSP hashes. Current `app.js` is 63,807 bytes; radio bundle is 64,647. Generator rejects individual literals at 65,536 bytes. A new identity helper may need a separate small asset rather than growing a near-limit literal. Update generated script ordering, hashes, route assets and configure dependencies together if extracting one. |
| [Design record](../../src/network/web/DESIGN.md), [CSS](../../src/network/web/style.css) | Preserve the flat light interface, native disclosure/controls, focus styling and mobile layout. Long hostnames need wrapping, not truncation into indistinguishable names. |
