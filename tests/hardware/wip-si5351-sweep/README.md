# Fixed-band Si5351 tone sweep

This opt-in standalone Pico 2 W diagnostic emits one finite steady CLK0 tone at each of 17 selected points from 2200 m through 2 m, including 8 m, 5 m and 4 m. It does not generate WSPR tones or claim a production Si5351 engine. Its I²C connection is GP4/GP5, 100 kHz, address `0x60`; output drive is 8 mA at the two LF points and 2 mA elsewhere. CLK1/CLK2 stay disabled during each test.

`plans.py` uses exact rational arithmetic and the equations in [Skyworks AN619 revision 0.8](https://www.skyworksinc.com/-/media/Skyworks/SL/documents/public/application-notes/AN619.pdf) to generate `plans.hpp` and an inspectable `plans.json`. All selected test frequencies have exact register representations for a nominal 25 MHz reference. The lower bands use a 900 MHz PLL and fractional MultiSynth0, with an R divider where needed. The 2 m point uses fractional PLLA at 866.943 MHz and integer MultiSynth0 divide-by-six. This is original MIT implementation, not copied upstream source. A TCXO's physical frequency error is separate from register arithmetic.

Use retained Pico SDK 2.3.1 and Arm GCC 15.3.1 with `-DPICO_NO_FLASH=1`. The CMake target refuses flash builds. Provide the existing pinned SDK and picotool sources explicitly, following the [development guide](../../../engineering/development/README.md). Build `Si5351BandSweep` in a separate private build directory. Recreate the plans with `python3 tests/hardware/wip-si5351-sweep/plans.py`, then format the header with the repository's clang-format settings.

USB `INFO` reports board serial and system clock. `TONE N` selects a zero-based plan index; each index is accepted once per boot. Runs last five seconds below 2 m and fifteen seconds at 2 m. Each run requires disabled physical outputs, snapshots touched registers, checks PLLA lock, emits a finite local tone, verifies shutdown, and restores the prior register values. During RF, USB disconnect or an `S` byte requests early shutdown. `STOP` independently requests output disable. I²C transactions have 10 ms deadlines; failed writes cannot prove inactivity. No Pico settings are written.

A hardware run must identify the board and path, check idle application state and disabled schedules, retain a private full-flash backup, and validate all UF2 payloads as SRAM addresses before loading. After testing, compare all flash bytes, reboot the original application, and verify identity, saved settings and inactive output. This follows the same restoration boundary as the [fixed tone diagnostic](../wip-si5351-tone/README.md).

Receiver measurements need independent quiet intervals, capture integrity, actual settings readback, and clipping/overflow checks. An available simultaneous locked GPSDO reference can remove common receiver frequency offset; it does not independently calibrate the receiver sample-rate scale. The sweep uses a reference 5 kHz below each test point; a 1 ppm sample-rate error would leave about 0.005 Hz of differential frequency error. Record reference settings before changes, make no persistent changes and restore exact settings afterward. Weak signals or references remain unresolved measurements rather than inferred passes. These steady tones do not qualify modulation, phase-continuous changes, RF power or emissions.
