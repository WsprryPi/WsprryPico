Setup Wi-Fi access window

Setup Wi-Fi stays available while a device is connected. After the last device disconnects, it closes after ten minutes without a connection. If nobody joins, the initial window lasts ten minutes. A USB Console request initially gives two minutes to join. Saving settings that restart the Pico can interrupt the connection. Release the configured switch and make a new nine-second hold to request setup again. The factory switch is GP14 to ground; saved custom or disabled assignments take precedence. USB access remains available.
