Station changes apply when saved. Pin changes need an explicit restart in Wi-Fi/Host.
Station identity is saved separately from schedules and radio pins.
Station identity
Type 1: one frame; compound + six-character locator: Type 2 then Type 3; <CALL> + six-character locator: Type 3. Maximum 12 characters including brackets.


Station identity





A compound call with a six-character locator uses two frames in adjacent even-minute windows. A bracketed call selects a Type 3 hash; receiver context may be needed.


Schedules and radio pins

One pair per line, for example 120 / 0. Up to eight schedules; use multiples of 120 seconds. Overlapping schedules are rejected. Standalone WSPR uses 3,570,100 Hz.


Pin assignments

Changes take effect after restart. Each GPIO can serve only one role. RF performance on a new pin requires validation.

Disconnecting station Wi-Fi closes that interface. Automatic setup Wi-Fi becomes available after one minute when the transmitter is inactive.
Temporary setup Wi-Fi
Hold the configured switch for nine seconds to stop transmission and open the Pico’s setup Wi-Fi. Release it to start the ten-minute access window. Join that network and open 192.168.4.1. If the saved network is unavailable, setup Wi-Fi starts automatically and remains available until the network recovers.
The factory switch connects GP14 (physical pin 19) to ground. A custom or disabled switch selection takes precedence. A quick tap resets the Pico; a shorter hold stops transmission.
