Disconnecting station Wi-Fi closes that interface. Automatic setup Wi-Fi becomes available after one minute when the transmitter is inactive.
Temporary setup Wi-Fi
Hold the configured switch for nine seconds to stop transmission and request setup Wi-Fi. Join that network and open 192.168.4.1. Setup Wi-Fi stays available while a device is connected. After the last device disconnects, it closes after ten minutes without a connection. If nobody joins, this initial window lasts ten minutes. Saving settings that restart the Pico can interrupt the connection. If it expires, release the switch and make a new deliberate nine-second hold; USB access remains available.
The factory switch connects GP14 (physical pin 19) to ground. A custom or disabled switch selection takes precedence. A quick tap resets the Pico; a shorter hold stops transmission.
