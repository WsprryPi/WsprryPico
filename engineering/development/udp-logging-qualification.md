## Review repairs and remaining gates

In-thread review and runtime findings repaired unsafe inference from native MESSAGE text, incomplete bundle-contract propagation, delayed journal-watch initialization, disabled-period replay, resource limits that were configured but not enforced, graceful station-withdrawal admission, empty-datagram classification, source-discovery/cursor races, long provenance overlap, mutable delivery-time origin drop counts, unreadable disabled controls and insufficient UI validation of active peer-slot membership/uniqueness, and incomplete uncertain-save review. Fresh authoritative settings are now displayed beside a preserved draft, with an explicit review guard before another write. Normal-image handback additionally exposed insufficient heap headroom for the unchanged WTP admission reserve: the queue now retains immutable approved-template indices instead of redundant maximum-length text buffers. Every approved template is tested after overwriting caller-owned strings; queue capacity, origin fields, safety reserves and wire semantics remain unchanged. Affected checks were rerun. This is not independent-agent review or RF qualification.

Physical two-board/two-member source-crossover and cable unplug/replug acceptance remains pending. The requested Pico C move to wspr4 has not been confirmed; physical USB inventory on wspr4 was empty. Software USB unbinding is not substituted for a cable test. Automatic approval review rejected starting that two-board case before the move was confirmed. Remaining physical acceptance must be completed before merging the coordinated feature or declaring it supported.

Final host restoration was verified after reboot on wspr2, wspr4 and wspr5. Original boot command lines, service units, INI, Fleet and USB policy bytes match the private originals; original installed Pi executables were untouched and their main services are active. Temporary simulated overrides and logging service/socket assets were removed, with no UDP listener remaining. The locked logging UID remains reserved for journal provenance without global journal-group membership or an active managed service. The web account's journal visibility was verified using metadata-only reads. Pico normal-firmware handback and final physical control readback remain execution-session obligations. Contract-2 handback uses a retained compatible normal bundle through the shared installer; the older image's larger reservation cannot be used as an automatic settings-preserving downgrade.
