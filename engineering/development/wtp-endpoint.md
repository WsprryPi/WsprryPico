# Native execution service

The portable JobService, engine, ownership, clock admission, cancellation, terminal observations, memory bounds, and fault recovery remain shared by native producers. See the normative [native execution contract](../protocol/Native-Execution.md).

External WTP execution is retired on TCP/plain/TLS, USB, BLE, and HTTP job wrappers. Application USB interfaces 2/3 are Reserved and inert; RFBench retains only its independent non-WTP Commands exception. There is no replacement remote job API. Commissioning, management/time, Console, and Logging retain their separate identities and security policies.

WTP probes, uploaders, monitors, and capacity campaigns cannot qualify this firmware. Independent Console diagnostics, decoding, calibration, and RFBench functions retain their own documented boundaries. Hardware/RF operations require separate authorization; host tests and builds establish software contracts only.
