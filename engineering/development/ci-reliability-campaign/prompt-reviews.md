# Prompt adversarial reviews

These records concern the eleven execution prompts, not implemented fixes.
For each prompt, a first authoring assessment identified the issue below, the
prompt was corrected before acceptance, and a second assessment checked its
scope, dependencies, failure gates, accounting, and consistency with the shared
contract. Additional cross-phase findings are recorded as they are closed.

| Phase | First assessment finding | Correction in accepted prompt | Second assessment |
| --- | --- | --- | --- |
| 01 | Documentation branch growth could contaminate the runtime denominator or replace the baseline silently. | Separate executable identity from document-only commits; freeze unknown slices and require explicit cumulative reconciliation. | Closed; read-only scope, missing-evidence outcome, reproducible sets, and handoff checked. |
| 02 | A replacement required-status aggregator could return success after selection failure; settings approval could be confused with code completion. | Fail closed for missing/unknown dependency results; prepare exact settings changes, require separate approval/readback, and keep enforcement pending explicitly. | Closed; cancellation, optional publisher skips, format readers, no-CI scope, and independent continuation checked. |
| 03 | Killing a parent group can miss detached descendants; blanket zero-exit checks can reject intentional shutdown, and failed cleanup can invite unsafe profile deletion. | Map each owned descendant, define fixture-specific orderly termination, retain errors, and preserve live profiles until teardown is confirmed. | Closed; partial reads, late replies/crashes, idempotency, fault restoration, secret handling, and both-carrier gates checked. |
| 04 | Filtering definitions could renumber ports, silently fall back, or self-certify the selected profile. | Validate selections before spawn, preserve original mapping/default opt-in contexts, and prove executed handler identity and observed owned-child counts. | Closed; expiry/draft/no-write sensitivity, bounded nested stages, import side effects, pilot limits, and both-carrier gates checked. |
| 05 | A suite-count target could erase the second message-frequency browser or section carrier; shared state and no-capture options could weaken isolation/assertions. | Separate launches, commands, and contexts; preserve reset/auth isolation and assertions under existing capture controls. | Closed; caller matrix, opt-in contexts, retry classification, real cold stimulus, extraction costs, and both-carrier gates checked. |
| 06 | A logical-clock seam could conflate monotonic/UTC/certificate time, and an ACK could mean queued rather than applied. | Keep clocks and crypto boundaries distinct; require observable ordered effects and execute the real cancellation callback boundary. | Closed; fault-entry observation, boundary sensitivity, finite real watchdogs, product timing, and both-carrier gates checked. |
| 07 | Activating tests under root could retain skips; a floating companion ref or an older peer could hide a current-contract mismatch. | Require the supported non-root context, strict execution evidence, an immutable current pair, and both production carriers; charge added coverage. | Closed; optional contexts, no real downloads/devices, old artifacts, companion authority, and single-current-control policy checked. |
| 08 | Matching object paths could hide differing flags; hidden object caches could invalidate fresh-build reproducibility, and clean rebuilds could mask broken dependencies. | Require full input equivalence, independent fresh compilation, verified source-only cache boundaries, and incremental tests without directory deletion. | Closed; per-image safety/link checks, independent artifact verification, replacement costs, no-change decisions, and both-carrier gates checked. |
| 09 | Job splitting could trust forged producer labels, drop required statuses, or claim causal speedup across different coverage. | Verify trusted job provenance, coordinate approved status transitions, retain resource exclusions, and compare identical current-coverage schedules separately from cumulative totals. | Closed; cancellation/partial artifacts, independent builds, hosted authority, overhead costs, and both-carrier gates checked. |
