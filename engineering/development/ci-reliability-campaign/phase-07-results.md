## Coverage and completion contract

The 39-case tool-download suite is registered on UNIX. Its first non-root Linux
execution passed all 39 cases in 1.242 seconds with zero skips. The suite uses
fake HTTPS, temporary HOME/cache, and a fake picotool that refuses USB operations.
It exercises consent/terminal/bootstrap prerequisites, cache ownership and locks,
archive and receipt tampering, traversal/symlinks, pending recovery, and cleanup
refusal. This activation adds coverage and receives no reduction credit.

The current producer requires execution-policy/2 and an immutable-source-bound
completion policy. All 56 registered Node/unittest frameworks bind to their actual
owned entrypoint and observed case count. Standalone npm, packaging, and lifecycle
contexts require 26, 64, and 39 cases respectively. Counts describe reviewed
current discovery, not performance quotas. Intentional coverage changes update
this inventory with their actual execution evidence. Optimized Python is refused
because existing behavioral fixtures use assertions. Ordinary non-root Linux is
required: a root-only skip is rejected rather than credited as consent coverage.

The producer rejects empty/partial discovery, failed/cancelled/skipped/TODO cases,
duplicate summaries, missing sources, wrong source roots, and undeclared observed
frameworks. CTest's default 1-KiB successful-output truncation hid two summaries;
the producer now retains up to one MiB per case and rejects truncated framework
evidence explicitly. This is an output retention bound, not a timing assertion.
Native standalone scripts retain their distinct completion facts; no mock-only
summary substitutes for their actual production checks.

The artifact reader loads policy from the frozen producer Git source, compares
the audit copy, and rechecks actual XML/logs and exact discovery. Malformed or
missing current policy fails; only frozen producers genuinely predating this
format retain their source-specific verification path. Deployment, storage,
transport, and shared control formats are unchanged.
